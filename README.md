# らくらくCSV君 / Rakuraku CSV Kun

## 日本語

**らくらくCSV君** は、通帳データや会計関連データの整理・CSV変換を支援する Windows 向けツールです。

手作業での転記、整形、CSV作成にかかる時間を減らし、日々の確認作業を効率化することを目的としています。

本リポジトリは公開配布用です。
